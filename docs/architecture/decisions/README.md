# Architecture Decision Records (ADR)

Ce dossier contient les décisions d'architecture du projet MyFinance.
Chaque ADR capture le contexte, la décision prise et ses conséquences.

## Format

Chaque fichier suit la convention `ADR-NNN-titre-court.md`.
