# Démarrage rapide

MyFinance est une application personnelle de gestion financière. Ce guide vous présente les étapes clés pour commencer à l'utiliser efficacement.

## Première connexion

Connectez-vous avec vos identifiants. Votre session reste active pendant 12 heures. En cas de trop nombreuses tentatives échouées, le compte est temporairement verrouillé (protection anti-brute force).

> ![Écran de connexion](/docs/demarrage-rapide/login.png) — Écran de connexion avec champs identifiant et mot de passe

## Navigation

La navigation principale se trouve en haut de l'écran sur desktop. Sur mobile, un menu bas donne accès aux sections les plus utilisées, et le bouton **Plus** ouvre un panneau complet.

> ![Bare de navigation Desktop](/docs/demarrage-rapide/navigation-desktop.png) — Barre de navigation desktop avec les menus déroulants (Revenus, Outils, Administration)

> ![Bare de navigation Mobile](/docs/demarrage-rapide/navigation-mobile.png) — Barre de navigation mobile avec le bouton Plus et le panneau coulissant

## Masquer les valeurs

Le bouton **œil** en haut à droite masque toutes les valeurs monétaires à l'écran. Pratique lors d'une présentation ou en lieu public. Le réglage est mémorisé entre les sessions.

## Ordre de saisie recommandé

Pour une expérience optimale, renseignez les informations dans cet ordre :

1. **Mon profil** → complétez votre profil fiscal (parts, abattement) et vos informations personnelles
2. **Revenus → Salariat** → créez votre contrat salarial actif
3. **Revenus → Complémentaires** → ajoutez vos autres sources de revenus (locatif, dividendes…)
4. **Dépenses** → listez vos dépenses récurrentes mensuelles et annuelles
5. **Passifs** → renseignez vos biens à décote (véhicule, électronique, mobilier…)
6. **Dettes** → ajoutez vos crédits en cours avec taux et mensualités
7. **Patrimoine** → créez vos positions financières (bourse, immobilier, livrets…)
8. **Tableau de bord** → consultez votre synthèse financière complète


## Tableau de bord

Le tableau de bord centralise en un coup d'œil :

- **Graphique d'évolution** du patrimoine par catégorie d'actifs
- **Widget FIRE** : projection vers l'indépendance financière et autonomie passive actuelle
- **Scoring patrimonial** : score sur 105 pts en 6 axes avec profil (FRAGILE → OPTIMISÉ)
- **Widget Dettes** : ratio d'endettement, date de libération, progression par type de crédit
- **Objectifs & Stratégie** : avancement radar par catégorie de patrimoine
