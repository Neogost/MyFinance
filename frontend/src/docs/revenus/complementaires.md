# Revenus complémentaires

La section **Complémentaires** regroupe tous les revenus hors salaire : loyers, dividendes, aides sociales et autres sources.

## Types de revenus

| Type | Exemples | Fiscalité |
|------|----------|-----------|
| **LOCATIF** | Loyer nu, location meublée | Intégré dans le simulateur d'impôts |
| **DIVIDENDE** | Dividendes d'actions, distributions | Intégré dans le simulateur d'impôts |
| **AIDE_SOCIALE** | CAF, APL, allocations chômage | Exonéré (non imposable) |
| **AUTRE** | Freelance, droits d'auteur, pension… | Intégré dans le simulateur d'impôts |

## Ajouter un revenu complémentaire

1. Allez dans **Revenus → Complémentaires**
2. Cliquez sur **Ajouter un revenu**
3. Choisissez le type, saisissez le libellé et le montant mensuel
4. Renseignez les paramètres fiscaux si nécessaire (abattement forfaitaire, régime micro…)

> ![Formulaire d'ajout](public/docs/revenus/other-income-form.png) — Formulaire d'ajout d'un revenu complémentaire avec les champs type, libellé, montant et options fiscales

## Affichage par catégorie

La page affiche un récapitulatif par type avec le total mensuel et annuel, ainsi que des **badges fiscaux** indiquant le régime d'imposition applicable.

> ![Page revenus complémentaires](public/docs/revenus/other-income-page.png) — Page des revenus complémentaires avec les badges fiscaux par catégorie et le total global

## Impact sur le bilan et les outils

Les revenus complémentaires sont utilisés dans :
- **Simulateur d'impôts** : calcul de l'IRPP avec l'ensemble des revenus
- **Bilan financier** : section Revenus (côté gauche du bilan)
- **Widget FIRE** : calcul du taux d'épargne et de l'autonomie passive

## Regroupement familial

Si vous faites partie d'un **groupe familial**, les revenus complémentaires du foyer peuvent être agrégés en activant le **Mode Foyer** depuis la navigation (icône maison). Seuls les membres du groupe sont inclus.
